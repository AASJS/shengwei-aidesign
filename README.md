# 圣为Ai设计 · 零依赖静态站

一个零依赖、可离线运行的纯静态网站，面向手机端：公众号排版 / 配色方案 / 标题 AB 测试 / 历史数据看板。

## 页面结构
| 文件 | 说明 |
|---|---|
| `index.html` | 首页 |
| `found-me.html` | 找到我 |
| `what-i-do.html` | 我能带你做 |
| `closed-loop.html` | 闭环 |
| `pain-points.html` | 痛点 |
| `course.html` | 课程 |
| `ai-start.html` | AI 起跑线 |
| `juezhao.html` | 觉照金句 |
| `signup.html` | 报名 |
| `圣为Ai设计-全站离线版.html` | 单文件离线版（iframe 内联全部页面，可双击运行） |

## 目录
- `scripts/build_offline.py` —— 离线单文件版构建脚本
- `sources/` —— 原始图片素材
- `docs/` —— 运营 SOP 与文案

## 本地预览
用浏览器直接打开任意 `.html` 即可；离线版单文件可双击运行，无需任何服务器与外链。
