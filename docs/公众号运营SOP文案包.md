# 公众号 SOP · 可直接抄文案包

> **自动回复 + 菜单栏 + 关注话术（圣为版）**
> 落款统一：来源：静心知识库｜@圣为Ai设计
> 用途：3 分钟把公众号「基建」套好，所有话术可直接复制粘贴到后台。

---

## 0 · 先用 30 秒对齐三件事

| 项 | 本包默认设定 | 你要确认 |
|---|---|---|
| 账号定位 | 用一套「入世」视角，陪你把说不清的卡点重解一遍；不鸡汤、不玄虚 | 若定位不同，改第 1 节首句 |
| 关注钩子（送什么） | 送《禅意知识卡片模板包》（可直接套用） | 换成你真正的引流品即可 |
| 承接方式 | 关键词自取 + 留言互动；不硬导二维码 | 上加微信/社群时注意合规 |

**后台硬规则（先记住）**
- 一级菜单名 **≤4 字**；子菜单名 **≤8 字**；最多 3 个一级菜单、每个 ≤5 个子菜单。
- 关键词回复务必选 **「半匹配」**（否则长词/别字收不到）。
- 被关注回复建议 **150 字内**，多了没人读完。
- 正文别放大段二维码、手机号，避免风控。

## 2 · 菜单栏（3 个一级 × 各 ≤5 子菜单）

**设计逻辑**：用户来你号里只干三件事 —— 认识你是谁、拿到价值、联系到你。菜单就围绕这三件事排。

### 布局总览（直接照这个搭）

| 一级菜单（≤4字） | 子菜单（≤8字） | 点开做什么 | 类型 |
|---|---|---|---|
| **开始这里** | 关于圣为 | 自我介绍长文/页面 | 跳转网页 |
| | 精选文章 | 页面模板：最值得读的10篇 | 跳转网页 |
| | 全部合集 | 进入你的合集列表 | 跳转网页 |
| | 新手必读 | 入门指南文章 | 跳转网页 |
| | 我的故事 | 个人成长文 | 跳转网页 |
| **免费领** | 卡片模板包 | 触发关键词「卡片」 | 发送消息 |
| | 建站清单 | 触发关键词「建站」 | 发送消息 |
| | 安心小册 | 触发关键词「安心」 | 发送消息 |
| | 加入社群 | 发送社群入口图/群二维码 | 发送消息 |
| | 合作咨询 | 商务合作说明 | 跳转网页 |
| **找我** | 加我微信 | 发送个人微信二维码图 | 发送消息 |
| | 我的课程 | 知识卡片入门课介绍 | 跳转网页 |
| | 预约咨询 | 一对一咨询说明 | 跳转网页 |
| | 商务合作 | 合作方式与邮箱 | 跳转网页 |
| | 意见反馈 | 留言引导 | 发送消息 |

### 3 个细节（决定这套菜单好不好用）

1. **文案要具象**：别写「免费福利」，写「免费领卡片模板包」——点的人多一倍。
2. **三个一级菜单都要填满**：空一格 = 白丢一份流量。
3. **尽量用「发送消息」**：它能激活自动回复，形成「点菜单 → 收话术 → 加微信」闭环。

> 小提示：新号期（0–5000 粉）优先「免费领 + 精选文章 + 加我微信」这三条，别铺太多。

## 3 · 关键词自动回复（最被低估的涨粉工具）

**技巧**：短词长词都设、同义词全覆盖、必设「无匹配回复」。词按下面表格配，回复文案可直接抄。

| 关键词（含同义词） | 自动回复文案（可直接抄） |
|---|---|
| **卡片** / 模板 / 知识卡片 | `卡片模板包给你放这儿了：<链接或领取方式>` ＋「觉得好用，欢迎转给也在做内容的朋友。」 |
| **建站** / 网站 / 搭建 / 做网站 | `《3天搭建网站》清单已发：<链接>` ＋「卡在哪一步，回复告诉我，我帮你看。」 |
| **安心** / 安心小册 | `《安心小册》领取入口：<链接>` ＋「它不解决所有事，但能陪你先把心放平。」 |
| **精选** / 10篇 / 好文 | `我把最值得读的 10 篇整理好了：<页面模板链接>` |
| **入门** / 新手 / 怎么开始 | `新手上路清单：<链接>` ＋「先看第一步，做完再看第二步，别贪多。」 |
| **课程** / 报名 / 学习 | `课程介绍与报名方式：<链接>` |
| **社群** / 进群 / 加群 / 交流群 | `社群入口：<二维码图或链接>` ＋「进去先看群公告，别急着自我介绍。」 |
| **合作** / 商务 / 广告 / 约稿 | `合作请加 <微信号>，或发邮箱 <邮箱>，注明来意，我看到会回。` |
| **无匹配**（兜底） | `暂时没找到对应的内容。你可以试试回复：「卡片」「建站」「精选」「社群」。或者直接说你的需求，我看到会回你。` |

**进阶·互动式回复**（把「搜索」变成「选择题」，互动率更高）：
```
回复「1」→《禅意知识卡片模板包》
回复「2」→《3天搭建网站》清单
回复「3」→ 加我个人微信
回复「0」→ 直接留言找圣为
```

## 4 · 收到消息默认回复（自动客服）

**引导型（推荐，能自助分流）**
```
收到你的消息了。我平时在写内容，回复不一定及时，见谅。

想快速拿到东西，回复关键词试试：
「卡片」模板包 ｜「建站」清单 ｜「精选」好文 ｜「社群」进群

急事直接留言说明来意，我会尽快回你。
```

**简约型（粉丝少时够用）**
```
收到你的消息了，稍后回复你。
```

> 什么时候该自定义：粉丝 5000+、每天私信 5 条以上、或你做不到 24 小时内回复时。

## 5 · 高级关注回复（可选 · 需绑定第三方工具）

新粉关注后 1 分钟内自动连发 3 条，对新粉沉淀最有效。三条这样排：

- **第 1 条**（总览）：放第 1 节主推版关注语。
- **第 2 条**（代表作）：`如果你只读一篇，先读这篇：<最拿得出手的一篇链接>`
- **第 3 条**（承接）：`想更近一步，回「微信」加我；只想安静看，回「精选」就好。`

## 6 · 套用 3 步 + 每月 15 分钟自检

**上手 3 步**
1. 后台 →「自动回复」：填「被关注回复」，开开关，保存。
2. 后台 →「自动回复」→「关键词回复」：按第 3 节逐条建，**记得选半匹配**。
3. 后台 →「自定义菜单」：按第 2 节搭 3×子菜单，保存发布（有 24h 缓存，更新后稍等）。

**每月 1 号花 15 分钟检查**
- [ ] 菜单文案是否过时？换当月热词
- [ ] 资料包链接是否还有效？
- [ ] 关键词是否漏了新常用词？
- [ ] 被关注回复要不要换个版本测一测？
- [ ] 商务联系方式/社群二维码是否还有效？

---

## 7 · 上线前必改的 4 个占位

1. **引流品名称** —— 把「禅意知识卡片模板包」换成你真正要送的。
2. **链接 / 领取方式** —— 第 3 节所有 `<链接>` 换成真实地址。
3. **个人微信 / 社群二维码** —— 「加我微信」「加入社群」要放能用的图（注意合规：别在正文大段放）。
4. **账号定位首句** —— 若定位与默认不同，改第 1 节第 2 句。
